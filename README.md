# Azure Data Factory Blob Copy Pipeline

## Objective
Copy a CSV file from source Blob container to destination Blob container using Azure Data Factory.

## Resources Used
- Azure Storage Account
- Azure Blob Containers
- Azure Data Factory
- Linked Service
- Source Dataset
- Destination Dataset
- Copy Data Pipeline

## Workflow
Source Container -> Get Metadata -> Copy Data -> Destination Container

## Result
File copied successfully:
Sample - Superstore.csv -> copied-superstore.csv
